# Local data

Generated and downloaded data lives here and is not committed.

- `raw/` — resumable downloads and tokenizer samples
- `processed/coder/` — base coder `train.bin`, `val.bin`, and `meta.pkl`
- `processed/fim/` — FIM binaries and metadata
- `processed/sft/` — SFT NumPy arrays
- `processed/bs_native/` — native BrittainScript specialist data
- `processed/bs_mixed/` — mixed translation specialist data

The source BrittainScript corpus remains in the sibling `bs-corpus` directory.
